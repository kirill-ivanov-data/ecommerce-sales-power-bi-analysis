# Ecommerce sales магазину товарів для тварин
## Структура проекту


## Висновок та рекомендації
1. Оптимізація витрат на логістику (+$29,55K до чистого прибутку)

Зараз витрати на доставку становлять $385,15K, що складає майже 90% від усього чистого прибутку компанії ($427,34K). Розрахунки показують, що доставка стає вигідною при замовленні від 3 одиниць товару. При цьому в категоріях Electronics (у середньому 1,38 шт.), Supplements (2,36 шт.) та Grooming (2,39 шт.) середній розмір позиції не дотягує до порогу рентабельності.   

Рішення: впровадити блок рекомендацій «Часто купують разом» і механіку бандлів для замовлень із категорій Electronics, Grooming та Supplements. Для масштабування цієї механіки на весь каталог варто провести A/B-тест динамічного алгоритму: для кожного обраного товару в кошику автоматично підтягувати індивідуальний топ-3 супутніх позицій на основі гістограми сумісних покупок та їхньої маржинальності. Доведення мінімального кошика до 3 штук знизить логістичні кости на 7,7% ($29,55K), що збільшить загальний прибуток бізнесу на 6,9%.

2. Масштабування високомаржинальної категорії (Electronics)

Electronics найбільш маржинальна категорія (44,28% при середній 27,50%), але з найнижчою частотою покупки (1,38 шт.) через специфіку товарів тривалого користування. Спостерігається регіональна аномалія: найбільші за виручкою ринки збуту (Каліфорнія, Техас, Флорида) показують слабку частку продажів в електроніці, тоді як лідирує за прибутком у цій категорії Массачусетс.

Рішення: вивчити структуру попиту та канали залучення в Массачусетсі й протестувати таргетовані кампанії на товари з цієї категорії в Каліфорнії, Техасі та Флориді, продаючи їх одразу в комплекті з розхідниками (ласощі/пелюшки), щоб не просаджувати метрики доставки.

3. Зауваження до якості даних (Data Quality)

У каталозі виявлено дублювання категорій (Food і Pet Food), а також некоректну прив'язку товарів тривалого користування (Memory Foam Pet Beds) до категорії одноразових розхідників (Disposables). Рекомендується провести ревізію довідника категорій у БД для підвищення точності майбутньої аналітики.
